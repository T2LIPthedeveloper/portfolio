# Atul Parida — Portfolio

Personal portfolio site built with Next.js 15, featuring siloed routes for work, projects, travel, and an OpenAI-powered chat assistant.

## Routes

| Route | Description |
|---|---|
| `/` | Home hero and featured teasers |
| `/about` | Bio, education, volunteering |
| `/work` | Experience timeline |
| `/projects` | GitHub project grid with search |
| `/travel` | Interactive 3D globe (flights + road trips) |
| `/chat` | Portfolio assistant (OpenAI) |

## Local Development

```bash
npm install
cp .env.example .env.local   # add OPENAI_API_KEY
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

**Important:** do not run `npm run build` while `npm run dev` is active. Dev writes to `.next-dev` (Turbopack); production build uses `.next` — separate caches prevent the usual chunk/manifest corruption. If you still hit a 500 / missing chunk error:

```bash
npm run clean
npm run dev
```
## Environment Variables

Create `.env.local` (never commit this file):

```bash
OPENAI_API_KEY=sk-proj-...
OPENAI_MODEL=gpt-4o-mini
OPENAI_REASONING_EFFORT=low
```

## Travel Data Workflow

See **[public/data/README.md](public/data/README.md)** for the full guide (CSV, destinations, trip mappings, road trips).

Short version:

1. Export flights from [my.flightradar24.com](https://my.flightradar24.com) to `public/data/flights.csv`
2. Add lifetime-only places to `public/data/destinations.json`
3. Group multi-leg trips in `public/data/trip-mappings.json` (use `date|flightNumber` keys)
4. Optionally add road trips to `public/data/road-trips.json`
5. Run the import CLI:

```bash
npm run travel:import
```

### Travel views

| View | Scope | Data sources |
|---|---|---|
| **Destinations** | Lifetime places & mapped trips | `destinations.json` + `trip-mappings.json` + road trips |
| **Pilot Mode** | Aviation log since 2017 | `flights.csv` (miles, aircraft, airlines) |

After updating travel JSON/CSV, always run `npm run travel:import` then restart/refresh the dev server.

## Data Files

| File | Purpose |
|---|---|
| `public/translations/en.json` | Portfolio content (preserved schema) |
| `public/data/flights.csv` | FlightRadar24 export |
| `public/data/road-trips.json` | Manual road trip polylines |
| `data/airports.json` | IATA → lat/lng lookup |
| `public/data/travel-manifest.json` | Precomputed globe payload (generated by CLI) |

## Tech Stack

- **Next.js 15** (App Router)
- **TypeScript** + Tailwind CSS v3
- **next-themes** — light/dark mode
- **react-globe.gl** — 3D travel globe
- **OpenAI API** — portfolio chat assistant
- **Framer Motion** — scroll and nav animations

## Deployment

Deploy to [Vercel](https://vercel.com). Set `OPENAI_API_KEY` in the Vercel project environment variables. Every PR gets a preview deployment automatically.
